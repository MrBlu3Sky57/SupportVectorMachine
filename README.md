# Classification
An implementation of a support vector machine for binary classification using the kernel trick. I am using this project as both a learning process and a way to build a practical piece of software that I can use on my computer. This repository will contain LaTeX files that describe the theoretical aspects of the machine learning algorithms I will be learning to implement, iPynb files for testing the algorithms on dummy data and general tinkering with the related mathematical concepts and finally a small app that I can use that combines the work done in the other parts of the project. I will update this README as I build the project and learn new things.
